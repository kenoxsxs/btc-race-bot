Two-horizon momentum trend bot trading Coinbase Wrapped BTC (cbBTC) on 1-minute bars. Long-only, full size: it enters when the close is above EMA(21) and both the 30-minute and 60-minute returns confirm the trend, and exits on a momentum reversal or an 80-bps trailing stop. Built for make.fun's "Race a BTC trading bot live for 24 hours" bounty.

## Run it

```sh
node main.ts
```
